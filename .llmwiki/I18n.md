# I18n

> Scope: how localisation is wired. For the procedure, use the `i18n-add-string` skill.
> Related: [[MobileApp]] · [[Testing]]
> Updated: 2026-09-11

## Facts

- **10 languages, 180 keys each, all fully translated** — none missing in any file
  (verified by JSON key count, not line count).
  `ar` · `de` · `en` · `es` · `fr` · `hi` · `ja` · `pt` (Brazilian) · `ru` · `zh` (Simplified).
  Arabic brings RTL.
- **`app_fr.arb` is the template**, `en` is the runtime fallback. This split is easy to get
  wrong: French carries all the `@key` descriptions (hence its 21 KB), English is what an
  unsupported locale resolves to.
- `l10n.yaml` is three lines: `arb-dir: lib/l10n`, `template-arb-file: app_fr.arb`,
  `output-localization-file: app_localizations.dart`. There is no `output-dir` and no
  `synthetic-package`, so generated files land in `lib/l10n/` and **are committed** —
  unlike `*.g.dart`, which is not.
- `pubspec.yaml` sets `flutter: generate: true`. Regenerate with `flutter gen-l10n`.
- The locale list exists **twice**: in the ARB files and again hardcoded in `main.dart`
  `supportedLocales`. Adding a language means touching both, or the ARB is generated and
  silently never selected.

### Usage

```dart
import '../l10n/app_localizations.dart';
final l10n = AppLocalizations.of(context)!;
Text(l10n.myString)            // plain
Text(l10n.welcomeUser('Alice')) // placeholder
Text(l10n.itemCount(5))         // ICU plural
```

### Rules

- Never hardcode a user-facing string. `Text('Bonjour')` is a defect.
- Never hand-roll a plural. `'$n item${n > 1 ? "s" : ""}'` is a defect — use ICU plural
  forms in the ARB, because the categories differ per language (Russian has 4, Arabic 6).
- Dates and times keep going through `intl`'s `DateFormat`, which is already locale-aware.
- User-generated content — player names, scores, game-type names — is never translated.

## Decisions & History

- **French is the template because the app was written in French first.** English is the
  fallback because it is the widest second language, so an unsupported locale degrades to
  something most users can read. The two roles being different files is a genuine footgun
  and the reason this page exists.
- **10 languages, chosen for reach.** Western (en, es, pt, fr, de), Asian (zh, hi, ja),
  Middle Eastern (ar, RTL), Cyrillic (ru) — roughly 5 billion native and secondary speakers.
- **Generated localisations are committed, generated Drift code is not.** Localisations
  change rarely and reviewing their diff is useful; `database.g.dart` is 7754 lines of
  churn. The inconsistency is intentional.
