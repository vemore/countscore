# Release

> Scope: the Play Store configuration state. For the procedure, use the `release-android` skill.
> Related: [[MobileApp]] · [[Testing]] · [[KnownLimits]]
> Updated: 2026-09-09

## Facts

Configured for Play Store release. The step-by-step guide is `PUBLISHING.md` at the repo
root.

### Signing

- Release signing is configured in `android/app/build.gradle.kts`.
- The upload keystore is generated by `./scripts/generate_keystore.sh`.
- `android/key.properties` is created from `android/key.properties.template`.
- Both the keystore and `key.properties` are excluded from version control. **Losing the
  keystore means the app can never be updated again** — back it up somewhere durable.
- ProGuard/R8 is **disabled**: the app is open source, so obfuscation buys nothing and
  costs debuggability.

### Build

```bash
flutter build appbundle --release --no-tree-shake-icons
# → build/app/outputs/bundle/release/app-release.aab
```

`--no-tree-shake-icons` is mandatory — see [[MobileApp]] for why.

### Icons

`flutter_launcher_icons` (dev dependency) generates every Android density from
`store_listing/assets/icon_512.png` (512×512 PNG). Adaptive icon on a white `#FFFFFF`
background. To change it: replace that PNG and run
`flutter pub run flutter_launcher_icons`.

### Target

API level 35 (Android 15), for 2025 Play Store compliance. App name "CountScore",
package `com.vemore.countscore`.

### Store assets

`store_listing/` holds the listing assets. `scripts/capture_screenshots.sh` pulls
screenshots over ADB. `privacy_policy.md`, `PLAY_STORE_DATA_SAFETY.md` and
`THIRD_PARTY_LICENSES.md` are the compliance documents.

### Blocker

`PUBLISHING.md` predates the backend entirely. It must be updated for the groups and
commentary stack — data safety declarations in particular — before any release that ships
either. See [[Security]] for what those declarations would have to disclose.

## Decisions & History

- **App Bundle, not APK, for the store.** Play requires it, and it lets Google serve
  per-device slices — which partly offsets the ~200 KB the icon tree-shake opt-out costs.
- **R8 disabled deliberately.** For an open-source app, obfuscation protects nothing that
  is not already public and makes crash reports harder to read.
- **The keystore is generated by a committed script rather than documented as manual
  steps**, so that regenerating it is reproducible — but the keystore file itself never
  enters the repository.
